# Clinical Trial Management System (CTMS)

## Project Description

The Clinical Trial Management System (CTMS) is a web-based application designed to streamline the management of clinical trials by providing centralized access to study information, participant records, regulatory documents, and trial workflows.

The system focuses on improving efficiency, maintaining regulatory compliance, and enabling secure collaboration among different stakeholders involved in clinical research.

---

## Key Features

| Module | Description |
|---------|-------------|
| Authentication | Secure login with role-based access control |
| Study Management | Create, update, and manage clinical studies |
| Participant Management | Register and maintain participant information |
| Investigator Management | Manage investigators and research staff |
| Site Management | Organize clinical trial sites |
| Regulatory Documents | Upload and manage trial documentation |
| Dashboard | Overview of studies, participants, and system activities |
| Audit Trail | Track important system actions |
| Reporting | Generate study-related reports |

# Installation

Clone the repository:

```bash
git clone https://github.com/Abishek-1212/Application-Development.git
```

Move into the project directory:

```bash
cd Application-Development
```

---

# Running the CTMS Project

### Backend

```bash
cd Backend
mvn spring-boot:run
```

### Frontend

```bash
cd Frontend
npm install
npm start
```
